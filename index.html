Google Drive

Not set up
Google Drive is not switched on yet. The register is saving on this device only.

To switch it on, do these two things once:

  1. In the Google Cloud Console, create an OAuth Client ID of type Web application, and under Authorised JavaScript origins add exactly this address:
  2. Paste the Client ID into js/config.js, on the googleClientId line, then upload that file again.

Full steps are in README.md. The Client ID is public by design — it is safe in that file, because Google only accepts it from the address above.

The register is always saved on this device first, so nothing is lost if Drive is unreachable. When connected it is also kept as one file in your Google Drive and merged with any other device on the same account — entries are combined, never overwritten. Google signs you out after about an hour; the bar at the top then says Reconnect, and any changes made meanwhile are kept and sent when you press it.

Qualities

Backup

A downloaded backup is the copy that does not depend on this browser or on Google. Take one regularly.

App Lock

A password keeps the register closed on a shared counter. It is stored on this device as a hash, not as plain text. It is a deterrent only — anyone with the files and some technical skill can still read the data. Real protection needs a server login.
